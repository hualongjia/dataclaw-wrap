# 调整 Agent OS 管理端菜单的权限查询时机

## Why

Chrome 在模型、应用和会话之间切换时，每次都串行等待当前权限和角色管理资格两个请求。六次采样中，仅这两项就耗时 305–841 毫秒，再次打开同一页面也会等待。

## What Changes

- 登录并首次进入后台时获取当前用户、租户的权限快照。普通菜单切换和回访直接复用该快照。
- 侧栏异步加载角色管理资格，得到肯定答复后显示入口。点击或直接访问角色权限页时核验资格，通过后再请求管理数据。
- 通过身份变化、可能影响本人的授权保存和权限拒绝事件刷新。页面按事件更新，无须配置 30 秒有效期或权限轮询。

### Modified Capabilities

- `admin-role-permissions` 增补普通导航、角色管理入口和权限状态失效时的查询行为。

## Impact

涉及 `apps/agent-os/web` 的路由守卫、权限状态、管理端侧栏、授权编辑及 API 错误处理。继续使用现有后端权限和资格接口，服务端对每次受保护操作独立鉴权。

# 会话产物抽屉实施任务

## 1. P3Demo 后端与第三方契约

- [ ] 1.1 在业务后端和共享类型中接入产物树。用混合目录、嵌套目录和空目录样例验证只返回当前个人会话 `generated/` 下的文件及层级，保留原文件节点 ID。
- [ ] 1.2 接入按节点预览和下载转发。验证文本预览与截断标记、图片二进制、原始下载文件名，并对三个入口验证跨租户、跨应用、跨用户及工作空间会话被拒绝。对预览和下载额外验证同一会话非交付文件及其他会话的节点被拒绝。
- [ ] 1.3 在 `dataclaw/docs/third-party-api/` 记录三个 Agent OS 上游路由、调用身份、产物目录判定和响应形态，并更新索引。逐项核对 JSON 预览与二进制下载的区别，标明 P3Demo 业务后端路径及联调状态。

## 2. React 抽屉与回答定位

- [ ] 2.1 在 `apps/web/src` 组合右侧 Drawer 和 EjTree，接入按会话加载的产物树。验证从页面入口可找到回答未提及的文件，重开后可再次选择，切换会话后空状态和迟到的响应不会残留旧内容。
- [ ] 2.2 接入 MarkdownRenderer 的文件引用处理。覆盖历史回答、已结束的流式回答、普通路径与显式文件链接，验证目录外引用保持文字、同名文件按完整路径定位，单次刷新后分别处理找到和仍缺失的节点。
- [ ] 2.3 接入按类型预览及原文件下载。验证文本、Markdown、代码、隔离的 HTML、鉴权图片、截断内容和不支持预览时的下载入口，确认图片资源在切换会话后得到释放。

## 3. 联调验收

- [ ] 3.1 通过 P3Demo 登录用户的一条个人会话生成含子目录的交付文件，从回答打开并下载，再重开会话从树中定位同一文件，核对文件名与内容。记录实际验证的上游接口和场景。
- [ ] 3.2 从第一轮回答预览一份产物，在同一会话的后续轮次覆盖原路径，再点第一轮的引用。验证预览和下载均为新内容。分别覆盖删除及移走文件的情形，验证旧引用仅刷新一次，原路径仍不可用时提示“文件暂不可用”，并且不会显示旧预览或打开其他目录的同名文件。

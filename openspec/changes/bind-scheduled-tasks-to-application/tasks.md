## 2. 写入与后台执行

- [x] 2.1 业务端创建和管理端复制时从已验证请求写入应用及创建人，覆盖伪造创建人、无有效应用、跨应用来源、业务端复制路由下线及更新凭据后归属不变的用例。
- [x] 2.2 在派发前比对任务归属和原执行身份，覆盖应用匹配、冲突及旧记录为空的场景，验证冲突时没有 Agent 调用。

- [x] 2.3 调整聊天工具对工作空间的处理及个人来源会话归属校验。用已授权 Agent 从个人会话创建提醒，分别覆盖缺省工作空间和占位值 `"0"`，验证任务关联当前会话、工作空间为空，并可按返回的任务 ID 从本人在当前应用的列表查到；覆盖跨用户、跨应用、跨租户来源被拒及工作空间会话创建回归。

- [x] 2.4 统一任务引用空间时的归属、成员及事务内校验。覆盖同租户跨应用（含空间所有者）、跨租户、同应用非成员、合法成员，以及知识范围单独指定空间；验证失败时无写入。对成员资格撤销后的手动与自动执行，验证在读取空间内容和派发 Agent 前终止；回归无空间个人任务。

- [x] 2.5 让页面、业务 API 和聊天工具在任务服务复用已验证应用的会话范围。分别验证 P3Demo 的显式空间 ID、空间来源会话、空间知识范围及间接空间引用均在写入前被拒，DataClaw Web 合法空间任务仍可创建。
- [x] 2.6 分开保存创建来源和正文依赖，联测删除会话与调度派发。用同一会话创建独立提醒与依赖正文的周期任务，验证删除后保留两项任务及历史、提醒继续、依赖任务暂停且详情显示原因。验证队列中旧触发、手动运行和直接恢复不能绕过暂停，编辑解除依赖后显式恢复成功。

## 3. Web 访问与集成验收

- [x] 3.1 对业务端列表、分页、汇总及读取附带的状态同步统一限定租户、应用、创建人；使用同租户双用户、双应用数据，验证按工作空间筛选后仍只计入当前用户的任务。
- [x] 3.2 业务端按同一范围访问详情、统计、执行记录和现有写操作，覆盖合法访问、同应用他人、本人跨应用、无应用及跨租户请求；核对拒绝时没有任务变更、执行或通知。
- [x] 3.3 验证 Agent OS Web 管理端有查看权限时能读取本租户全部用户和应用的任务及执行历史，缺少权限或跨租户时拒绝。回归后台到期执行使用任务自身身份。
- [x] 3.4 按设计表接入 P3Demo 的 11 个接口，逐项核对 HTTP 方法、路径、用户凭据和应用上下文；联调创建、分页列表和详情，对照 DataClaw Web 核验配置、状态及最近执行结果。
- [x] 3.5 经 P3Demo 验证暂停后编辑仍保持暂停、恢复按新计划调度、立即运行产生手动记录、删除后任务及历史不可见。对编辑、暂停、恢复、立即运行和删除逐项验证同应用他人及本人跨应用请求均被拒绝，原任务和执行记录无变化。
- [x] 3.6 三个执行查询入口统一先校验父任务再同步或读取。验证历史翻页、单次执行定位、统计按需加载及数值；覆盖同应用他人、本人跨应用、跨租户及执行 ID 与父任务不匹配，请求被拒绝时无越权同步或数据返回。
- [x] 3.7 从 P3Demo 智能问答页的定时任务入口，以登录用户完成个人任务创建、列表定位、查看详情、暂停、编辑、恢复和立即运行。查看执行历史、单次执行详情及统计，最后删除测试任务，验证页面正确反映每一步结果。
- [x] 3.8 随实施更新 `dataclaw/docs/third-party-api/scheduled-tasks.md`。逐项核对 11 个 Agent OS 上游接口的身份、请求、响应和错误示例，将 P3Demo 转发路径单列为接入示例。用真实第三方身份验证个人任务的空间限制、删除来源会话后的两类任务行为及相应接口调用，按实测范围更新主题和 README 的状态。

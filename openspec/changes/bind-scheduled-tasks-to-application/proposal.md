## Why

P3Demo 与 DataClaw Web 共用定时任务服务。现有业务端按租户读取任务，用户能看到同事创建的任务及自己在其他应用创建的任务。

## What Changes

- 业务端创建任务、管理端复制任务时持久化经过验证的应用归属。
- 用户可以在普通个人会话中让已授权的 Agent 创建个人定时任务，创建结果可在当前应用的个人任务列表中查看。
- P3Demo 首期仅支持个人任务，页面、API 和聊天工具统一拒绝工作空间引用。DataClaw Web 继续按租户、应用及空间成员权限创建工作空间任务。
- 删除来源会话时保留任务及执行历史。仅记录来源的任务沿用原计划，仍需读取已删除正文的任务暂停并告知原因。
- **BREAKING** 业务端的列表、统计、详情、执行记录及操作限定为当前用户在本租户、当前应用创建的任务。Agent OS Web 的定时任务管理页供具备查看权限的用户查看租户全量任务。
- P3Demo 首期与 DataClaw Web 共用 Agent OS 的 11 个业务端接口：创建、分页列表、详情、编辑、暂停、恢复、立即运行、删除、执行历史列表、单次执行详情和任务统计。P3Demo 通过自己的后端转调，统计按需加载。
- 下线业务端模板列表与复制任务路由。管理端沿用独立的复制接口。
- 根据可信的既有执行上下文回填历史任务；来源待确认的记录保留空归属，后台沿用原有执行校验。

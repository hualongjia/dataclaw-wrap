# Spec Delta

## ADDED Requirements

### Requirement: 同步目标管理界面

管理端 SHALL 为具备目录同步权限的操作者提供全局同步目标列表，并通过统一的管理端交互支持新增、启用、停用、移除和手动同步。

#### Scenario: 新增与移除目标
- **WHEN** 操作者新增或移除同步目标
- **THEN** 页面通过表单收集租户 ID，并在移除前要求确认
- **AND** 操作成功后刷新对应列表，失败时显示原因并允许重试

#### Scenario: 手动同步启用目标
- **WHEN** 操作者选择一个启用目标或全部启用目标进行同步
- **THEN** 页面提交对应范围，并在服务端接受后显示执行进度或历史
- **AND** 停用目标不可单独触发，没有启用目标时全部同步不可用

### Requirement: 执行历史与逐租户详情

管理端 SHALL 按执行分页展示持久化历史，并提供每次执行的逐租户详情。

#### Scenario: 从历史打开详情
- **WHEN** 操作者打开某次执行的详情
- **THEN** 页面展示该次执行的逐租户状态、用户数及可用的失败原因
- **AND** 关闭详情后回到原历史页码

#### Scenario: 查看正在执行的任务
- **WHEN** 页面检测到执行中状态
- **THEN** 页面自动刷新执行状态，支持查看最终结果
- **AND** 刷新失败时保留已加载的记录并提供重试入口

# 实施与验收

## 1. PostgreSQL 队列与执行标识

- [x] 1.1 锁定兼容的 pg-boss 版本并接入 Nest worker 生命周期；在目标 PostgreSQL 上验证两个进程共享队列、正常停机和 Prisma 事务回滚时无残留作业。
- [x] 1.2 增加计划版本、自动触发唯一键、执行持有者与阶段及通知投递记录；在含旧历史和手动执行的升级库验证迁移可用，重复自动触发只能关联一个雪花执行 ID。

## 2. 计划与执行

- [x] 2.1 将创建、复制、改期、暂停、恢复、删除与延时作业协调；限定 `Asia/Shanghai`，统一接口、工具及数据库默认值；针对五类计划验证跨日期、年界、非上海拒绝和失效版本作业。
- [x] 2.2 接入事务领取与后继入队；双实例同时处理同一时刻、重投和逾期触发时，核对执行条数、Agent 调用数、下一时刻及一次性任务终态。
- [x] 2.3 从共享执行状态协调手动运行、长任务续租和暂停；并发验证同任务串行、立即运行响应、状态不被旧 worker 覆盖，以及正常长任务不被旧超时逻辑误判。
- [x] 2.4 接入应用归属变更的运行身份校验；在排队后撤销绑定或使凭据失效，验证拒绝发生在模型调用前，且队列载荷没有凭据。

## 3. 故障恢复与通知

- [x] 3.1 持久化 Agent 派发阶段并恢复同一执行 ID；分别在派发前、下游接受后、结果提交后终止 worker，验证可安全重试的阶段继续，结果未知且无法核对的阶段停止重发。
- [x] 3.2 事务保存结果与待投递目标；覆盖部分投递成功、进程退出和队列重投，核对每个目标的送达记录、未知结果提示及失败计数。

## 4. 旧计划切换

- [x] 4.1 实现可重跑的导入和切换指引，先只读检查非上海历史任务，存在仍可能进入执行的记录时暂停等待明确处置决定，已删除历史原样保留；在历史样本库中重复导入并核对已到期、未来、暂停、完成、删除和在途任务。
- [ ] 4.2 在共享 PostgreSQL 的双实例环境演练旧轮询停用、新 worker 启用、重启接管与回退；对照下一时刻、执行历史和通知确认无双触发，并运行现有 scheduled-tasks 回归测试。

# Spec Delta

## Purpose

为管理端、用户端和桌面端提供独立的 Auth3 登录入口，使用户在当前租户下继续使用原工作区、记忆管理与已有消息通知功能。

## ADDED Requirements

### Requirement: 三端登录
系统 SHALL 绑定 Client、回调、state 和 PKCE S256。

#### Scenario: 成功回调
- **WHEN** 任一端完成授权
- **THEN** 从原端换票路由登录，用户及租户 ID 对应已有业务记录

#### Scenario: 事务错配
- **WHEN** state、端或 verifier 不匹配
- **THEN** 拒绝建立会话

#### Scenario: 桌面登录入口
- **WHEN** 未登录用户打开桌面端
- **THEN** 通过系统浏览器完成 OAuth 登录并以深链返回；桌面不提供密码登录表单或密码登录 IPC

### Requirement: 浏览器独立会话
系统 SHALL 为 WebAdmin 和用户 Web 分别建立服务端会话，Auth3 用户令牌仅保存在服务端。

#### Scenario: 同浏览器登录两端
- **WHEN** 用户在同一浏览器分别登录管理端和用户端
- **THEN** 两端分别获得签名的 HttpOnly 会话 ID，换票响应及浏览器存储均不包含 Auth3 令牌，跨端使用或篡改会话 ID 时拒绝认证

#### Scenario: 多实例验证和空闲到期
- **WHEN** 用户在一个实例登录，随后由其他实例处理会话请求
- **THEN** 各实例从共享 Redis 解析相同身份，只有后台探测时滑动租约仍按期失效

#### Scenario: 切换或撤销期间存在并发请求
- **WHEN** 一端成功切租户或退出，另一实例随后收到原会话 ID 或完成此前在途的请求
- **THEN** 原会话无法继续访问或被恢复，另一端的独立会话仍可使用

#### Scenario: 两端登录前获取 CSRF 令牌
- **WHEN** 尚未建立会话的浏览器打开 WebAdmin 或用户 Web
- **THEN** 系统 SHALL 支持该端获取独立的随机 CSRF Cookie，供前端在登录发起和回调换票请求中通过专用请求头回传

#### Scenario: 两端合法写请求
- **WHEN** 同一浏览器同时使用两端，分别从允许的来源提交本端的匹配令牌
- **THEN** 系统 SHALL 允许通过 CSRF 校验，两个端各自的普通写入、切租户和退出按本端会话处理，登录会话 Cookie 保持 HttpOnly

#### Scenario: CSRF 校验失败
- **WHEN** 任一端的登录发起、回调换票、普通写入、切租户或退出请求来源非法，或 CSRF Cookie 与专用请求头任一缺失或令牌不匹配
- **THEN** 系统 SHALL 在产生业务副作用前返回 403，登录事务、会话、当前租户及业务数据均保持请求前状态

### Requirement: 会话生命周期
系统 SHALL 支持当前租户、登出及已配置的令牌策略。

#### Scenario: 滑动令牌
- **WHEN** 有效滑动令牌未带刷新令牌
- **THEN** 用户可登录，后续验证遵循 Auth3 租约

#### Scenario: 三端用户活动续租
- **WHEN** 管理端、用户端或桌面端由用户交互触发本端活动上报，且滑动令牌有效
- **THEN** 系统 SHALL 使用该用户令牌向 Auth3 续租一次，包括桌面端以 Bearer 令牌上报的情形

#### Scenario: 普通请求、后台轮询与恢复探测
- **WHEN** 任一端发出普通业务请求、后台轮询或页面恢复探测
- **THEN** 系统 SHALL 在认证流程中仅验证令牌，这些请求不会触发活动续租

#### Scenario: 滑动模式关闭自动刷新
- **WHEN** 任一端在滑动模式下发出请求，无论是否携带刷新令牌
- **THEN** 系统 SHALL 禁止自动刷新用户令牌，租约失效时拒绝请求并要求重新登录

#### Scenario: 切换与登出
- **WHEN** 用户切租户再退出
- **THEN** 权限按新租户加载，退出后受保护页面要求认证

### Requirement: 既有目录与通知
系统 SHALL 通过 Auth3 保留工作区用户解析、记忆范围及定时消息。

#### Scenario: 根组织
- **WHEN** 管理员读写部门记忆
- **THEN** 只允许当前租户根组织范围；目录失败时不会扩大范围

#### Scenario: 用户与附件
- **WHEN** 工作区查询成员或任务发送带附件通知
- **THEN** 返回原用户资料或向原收件人交付附件

### Requirement: 租户写入与会话边界
系统 SHALL 在两个 Web 端校验页面预期租户、串行执行同一会话的租户切换，并执行独立于滑动租约的本地固定截止时间。

#### Scenario: 旧标签页提交
- **WHEN** 业务写请求缺少页面预期租户，或旧标签页在另一标签页切租户后提交
- **THEN** 服务端在业务写入前拒绝请求

#### Scenario: 并发切换与未知结果
- **WHEN** 两个实例收到同一会话的切换请求
- **THEN** 至多一个请求同时派发，用户、目标租户及 Client 校验通过后原子切换；上游结果未知时阻止旧凭证写入及请求自动重放

#### Scenario: 固定截止与上游故障
- **WHEN** 持续操作的用户到达本地会话固定截止时间
- **THEN** 要求重新登录；截止前若鉴权遇到网络或机器凭证故障，则拒绝本次请求并保留登录批次

### Requirement: 退出回调防重放
系统 SHALL 将退出事务绑定到端、浏览器和登录批次，并在五分钟内原子消费一次性 state。

#### Scenario: 回调迟到或重复
- **WHEN** 退出回调过期、绑定错误或重放，或原用户在回调到达前已重新登录
- **THEN** 拒绝无效回调，有效回调只确认原事务，新登录会话继续可用

### Requirement: 浏览器内容安全策略
两个 Web 端 SHALL 通过部署入口发送限制脚本、网络连接、表单和页面嵌入的 CSP 响应头。

#### Scenario: 部署后访问
- **WHEN** 用户在任一端完成 OAuth 登录、回调并使用业务页面
- **THEN** 所需资源和 API 可访问，浏览器阻止策略之外的脚本、连接和表单提交，并拒绝其他页面嵌入本应用
